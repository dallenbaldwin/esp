# CONTRIBUTING.md

You should have vite plus installed globally, even if it's defined in the
`package.json`. This repo was migrated to vite plus using `vp migrate`

```bash
vp --help
```

## Install Dependencies

```bash
vp install
```

## Development

Run the development server

```bash
vp dev
```

Build & Preview

```bash
vp build
vp preview
```
